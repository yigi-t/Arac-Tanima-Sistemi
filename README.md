# Araç Tanıma ve Sınıflandırma Sistemi

YOLOv8 mimarisi kullanılarak geliştirilmiş, web tabanlı bir araç tanıma sistemidir. Bu proje, derin öğrenme yöntemleri ile araç tespiti yapabilmekte ve Flask üzerinden kullanıcı dostu bir arayüz sunmaktadır.

## 🚀 Özellikler
- **Model:** YOLOv8n (Nano) tabanlı özel eğitilmiş ağırlıklar (`best.pt`).
- **Arayüz:** Flask tabanlı web uygulaması.
- **Geçmiş:** Son yapılan 10 analizi hafızada tutma ve görüntüleme.

## 🛠️ Kullanılan Teknolojiler ve Kütüphaneler
Projenin çalışması için aşağıdaki temel kütüphaneler kullanılmıştır:
- **Python 3.x**
- **Ultralytics (YOLOv8):** Nesne tespiti ve model yönetimi.
- **Flask:** Web sunucusu ve API yönetimi.
- **OpenCV:** Görüntü işleme operasyonları.
- **Pillow:** Resim formatı düzenlemeleri.
- **PyTorch:** Modelin derin öğrenme altyapısı.
